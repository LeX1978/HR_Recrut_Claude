# Changelog

История личного форка. Формат основан на [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Без отслеживания upstream, без тегов, без релизов - записи это датированные заметки для себя-будущего, а не публичный лог релизов.

## [Unreleased]

### Added

- **`/pipeline`** — единая команда полного цикла: ранжирует неотранжированные строки `Вакансии.md` по фреймворку `04-job-evaluation.md`, показывает шорт-лист с одним чекпоинтом подтверждения, помечает выбранные строки «Откликаться» = `Да` и запускает по ним Queue Mode `/apply` — без ручного чередования `/rank` → правка Obsidian → `/apply`.
- **Конвенции `companies/` и `applications/` в Obsidian vault** - `01-PROJECTS/поиск-работы/companies/<company>.md` (кэш исследования) и `applications/<company>_<role>.md` (одна заметка на заявку: вакансия, оценка соответствия, CV-рекомендации, сопроводительное письмо, подготовка к интервью, статус) заменяют локальные для репозитория `company_research/*.json` и `documents/applications/**` как основную запись, читаемую человеком.
- **В `Вакансии.md` добавлены колонки Оценка / Вердикт / Архетип**, заполняемые `/apply` (а позже `/rank`) по мере продвижения вакансии по воронке.
- **Проход `humanizer-ru` в `/apply`** - текст сопроводительного письма и CV-рекомендаций прогоняется через `humanizer-ru:humanize`, затем `humanizer-ru:audit` перед показом пользователю, оценка ЧИСТОТА логируется в заметке заявки.
- **OAuth на базе `.env` для hh.ru** (`hh-search`, унаследован от `ai-job-search` до форка) - регистрация на dev.hh.ru - ручной шаг, который выполняет сам пользователь, здесь не автоматизирован.

### Changed

- **Obsidian становится основным хранилищем.** `/apply`, `/outcome`, `/interview` теперь сначала пишут результат, читаемый человеком, в vault; локальные для репозитория `job_search_tracker.csv`, `documents/applications/**` и `company_research/*.json` сохраняются как вторичный индекс для `/rank`, `/html-report` и `/upskill`, а не удаляются.
- **PDF сопроводительного письма теперь опционален, а не по умолчанию.** Большинство откликов в РФ идут через текстовое поле портала; скомпилированный PDF создаётся только когда вакансия/портал явно требуют файл-вложение. Обязательный цикл compile-and-inspect в `CLAUDE.md` и `06-cover-letter-templates.md` теперь зависит от этого решения.
- **Eligibility Gate в `04-job-evaluation.md` ограничен зарубежным треком.** Проверка гражданства/визы/допуска больше не запускается по умолчанию на внутреннем рынке РФ/СНГ, где она почти никогда не применима.
- **`/scrape` читает `source.md` напрямую из Obsidian** вместо того, чтобы полагаться на скопированный вручную список площадок в `search-queries.md`.

### Fixed

- **`hh-search`: кэш токена писался вне репозитория.** Путь к `.token-cache.json` собирался через `URL.pathname`, который кодирует кириллицу в пути (`~/Projects/Рекрутер` → `%D0%A0...`), поэтому токен сохранялся в соседнюю папку с закодированным именем. Теперь используется `fileURLToPath`, добавлен регрессионный тест. Заодно впервые проверена работа с реальным ключом dev.hh.ru (24-09-2026): `search` и `detail` возвращают живые данные.
