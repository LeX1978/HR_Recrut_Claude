# Рекрутер

Личный инструмент поиска работы на Claude Code, адаптированный под рынок России/СНГ. 

Движок (код, правила, шаблоны) живёт здесь, в репозитории. **Вся содержательная информация — вакансии, оценки, рекомендации по резюме, сопроводительные письма, статус откликов, исследования компаний — хранится в Obsidian**, в проекте `01-PROJECTS/поиск-работы/` в Obsidian. 

## Что умеет

| Команда | Делает |
|---|---|
| `/scrape` | Ищет вакансии по площадкам из `source.md` (Obsidian) через портальные CLI + WebSearch-фолбэк, кладёт найденное в очередь |
| `/rank` | Батч-оценка вакансий по фреймворку соответствия, шорт-лист |
| `/apply` | Полный цикл заявки: оценка fit → рекомендации по резюме (не новое резюме, доработки к одному из трёх типовых) → сопроводительное письмо → ревью → проверка. `/apply queue` обрабатывает всю очередь из `Вакансии.md` сразу |
| `/interview` | Пакет подготовки к конкретному собеседованию на основе реально отправленных материалов |
| `/outcome` | Фиксирует результат отклика, ведёт трекер и архив |
| `/setup` | Онбординг профиля кандидата |
| `/add-portal` | Генерирует CLI-скилл для новой площадки поиска вакансий |
| `/add-template` | Регистрирует кастомный шаблон резюме/письма |
| `/expand`, `/upskill`, `/html-report`, `/reset` | Вспомогательные: обогащение профиля, анализ разрыва навыков, офлайн-дашборд, сброс |

## Портальные CLI

- **`hh-search`** — hh.ru, официальный API `api.hh.ru`. Требует регистрации приложения на [dev.hh.ru/admin](https://dev.hh.ru/admin) (OAuth2 `client_credentials`) и `.env` с `HH_CLIENT_ID`/`HH_CLIENT_SECRET` в корне репозитория — см. `.agents/skills/hh-search/SKILL.md`.
- **`linkedin-search`**, **`freehire-search`** — страно-агностичные, работают из коробки.
- **career.habr.com, geekjob.ru, getmatch.ru, choicy.work** — пока без выделенного CLI, идут через WebSearch-фолбэк (`site:`-запросы в `.claude/skills/job-scraper/search-queries.md`). Кандидаты на CLI через `/add-portal`, hh.ru был приоритетом №1 и уже сделан.

## Установка

```bash
git clone <ваш форк> Рекрутер
cd Рекрутер
# hh-search:
#   1. зарегистрировать приложение на dev.hh.ru/admin
#   2. создать .env с HH_CLIENT_ID / HH_CLIENT_SECRET
for tool in linkedin-search freehire-search hh-search; do
  (cd .agents/skills/$tool/cli && bun install)
done
```

Профиль кандидата (`CLAUDE.md`, `.claude/skills/job-application-assistant/01-07-*.md`) заполняется через `/setup`

Важное дополнение!!!!
После установки папки claude и agents должны быть скрытыми. Это актуально для Linux систем. На Windows не тестировалось, информации нет !!


## Устройство

- `.claude/commands/` — slash-команды (шаги воркфлоу)
- `.claude/skills/job-application-assistant/` — профиль кандидата, фреймворк оценки, шаблоны письма/резюме, правила стиля
- `.claude/skills/job-scraper/` — логика `/scrape`, поисковые запросы по приоритетам
- `.agents/skills/*-search/` — CLI-скиллы поисковых площадок (TypeScript, Bun)
- `tools/` — вспомогательные Python-скрипты (дедуп-ключи, проверка вёрстки PDF, guard-скрипты для CI-подобных проверок настроек)
- `tests/` — юнит-тесты, гоняются `python3 -m unittest discover -s tests`

## Личные данные

Всё, что раньше лежало в `job_search_tracker.csv`, `documents/applications/**`, `company_research/*.json` в репозитории, остаётся как гитигнорённый вторичный индекс — основной источник правды теперь Obsidian (`Вакансии.md`, `companies/`, `applications/`). Ничего из этого не коммитится и никуда не отправляется без явного запроса.

## Нет пуша на GitHub

Коммиты — только локальные (решение пользователя). Нет `.github/` workflow'ов, нет CI, нет удалённого репозитория по умолчанию.
